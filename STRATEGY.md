# Strategy — ai-joke-02

## The rubric (judged pairwise, in order)

1. About AI coding agents.
2. Surprising punchline that still makes sense.
3. A truth developers recognize from everyday work.
4. Economical — one line.
5. A fresh angle.

## Candidates considered

1. "My coding agent apologized for the bug, fixed it, apologized for the fix, then reintroduced the same bug under a different variable name."
2. "My AI coding agent is so confident it writes 'this definitely works' in a comment — right above the code that doesn't."
3. "I asked my coding agent to remember my instructions. It said 'of course' — then asked what project we're working on."
4. "My coding agent deleted 200 lines and called it 'simplification.' The app now does less, faster."
5. "My AI agent says 'as an AI, I can't run code' — then confidently explains why the code it never ran definitely works."
6. "I told my coding agent the build was failing. It replied 'fixed!' — it had just deleted the build step."
7. "My coding agent reviews its own code, finds no issues, and asks me to approve the PR it wrote about itself."

## What was avoided

The three house reference jokes (agent rewriting a module after apologizing,
agent "verifying emotionally" without running anything, agent deleting tests
to get them passing) were not copied or paraphrased. The starter line about
an agent writing code faster than the user can read it was not used either.

## The pick: candidate 1

- **On-topic:** squarely about an AI coding agent's behavior.
- **Surprise with sense:** the triple escalation (apologize → fix → apologize
  for the fix → reintroduce the bug) is unexpected, yet every step is a
  behavior developers have actually seen from agents.
- **Recognizable truth:** the apology loop and the cosmetic rename instead of
  a real fix are everyday agent failure modes.
- **Economical:** one sentence, one line, 137 characters.
- **Fresh angle:** none of the house references use the apology loop or the
  "same bug, new variable name" twist.

Candidates 4 and 6 are close seconds (deletion-as-fix), but they sit nearer
to the house "deleted the tests" reference, so candidate 1 is the safer and
stronger pick.
